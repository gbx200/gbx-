## 1. 项目背景与目标
	实现一个图书管理系统，图书管理：图书借阅与归还，图书录入，图书的查询与检索，图书状态；用户管理：注册与登录，个人信息维护；
## 2. 用户角色分析
	1. 普通读者：
		1. 注册，登录，修改个人密码及基本信息
		2. 浏览图书列表，根据书名/作者/ISBN进行模糊搜索，查看图书详情（如库存状态）。
		3. 发起图书借阅请求，查看自己的当前借阅和历史借阅记录。
		4. 确认归还图书，查看是否产生逾期记录。
		后端权限控制策略 (DRF)：只能访问自己相关的数据；禁止访问管理端接口（如添加图书、删除用户）。
	2. 图书管理员：
		1. 包含读者权限：管理员通常也具备读者的所有功能（可以借书、查书）。
		2. 图书资产管理：录入新书（创建图书信息）。；修改图书信息（如更新库存、修改简介）。；下架/删除图书。
		3. 读者管理：查看所有读者列表。；禁用/启用违规读者账号。
		4. 全局数据查看：可以查看全系统的借阅记录（不仅限于自己的），用于日常盘点。
## 3. 功能需求列表（按优先级划分）
### 1.核心基础功能：
	1. 用户认证模块
		读者注册与登录（基于 JWT Token）。
		获取当前登录用户信息。
	2. 图书信息模块
		图书列表展示（支持分页）。
		图书检索（支持按书名、作者模糊搜索）。
		图书详情查看。
	3. 借阅业务模块
		发起借阅请求（需校验库存和借阅数量限制）。
		归还图书（更新借阅状态，计算是否逾期）。
		个人借阅记录查询（当前在借、历史借阅）。
	4. 个人中心模块
		查看与修改个人基本信息。
		修改登录密码。
### 2.管理与进阶模块：
	1. 后台管理模块（管理员专属）
		图书的增、删、改操作（录入新书、修改信息、下架图书）。
		读者账号管理（查看列表、禁用/启用违规账号）。
		全局借阅记录查看。
	2. 业务扩展模块
		借阅续期功能（在应还日期前允许续借一次）。
		逾期状态高亮与简单违约金计算。
### 3.其他模块：
	1. 数据可视化大屏
		统计并展示“月度借阅 Top10 图书”、“各分类图书占比”（前端配合 ECharts 实现）。
	2. 消息通知模块
		站内信提醒（如：预约的图书已到货、借阅即将逾期提醒）。
		数据导出功能
		管理员可将借阅记录或图书列表导出为 Excel 文件。
